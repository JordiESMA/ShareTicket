# Lista de Compra Compartida

Aplicación Android desarrollada con Kotlin y Android Studio para crear y gestionar listas de compra compartidas.

## Funcionalidades

- Inicio de sesión mediante OAuth 2.0.
- Crear y gestionar múltiples listas.
- Compartir listas con otros usuarios.
- Crear, editar y eliminar categorías.
- Crear, editar y eliminar productos.
- Marcar productos como completados sin eliminarlos.
- Gestión de listas propias y compartidas.

## Tecnologías

- Kotlin
- Android Studio
- OAuth 2.0
- Android SDK
- Gradle
